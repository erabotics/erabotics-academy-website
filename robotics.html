Robotics Track

Robots that actually move, sense, and react

Mechanics, electronics, and control systems — students go from first assembly to building autonomous behavior, one working robot at a time.

What you'll learn

Inside the Robotics track

🔩

Mechanical build

Chassis assembly, gearing, and structure — understanding how a robot's body supports what it needs to do.

⚡

Electronics & wiring

Motors, sensors, and microcontrollers — how to wire, power, and troubleshoot a real circuit.

💻

Programming & control

Writing the code that turns sensor input into robot behavior — from simple reactions to closed-loop control.

🧭

Navigation & sensing

Using distance, vision, and motion sensors to let a robot understand and move through its environment.

🛠️

Real fabrication tools

Access to ERABOTICS' own fabrication lab to build custom parts for a student's own robot design.

🏆

Competition-ready builds

Advanced students refine a robot to a standard that's ready to enter into robotics competitions.

Path

How the track progresses

01

Foundations

Build and program a first robot using a guided kit — no prior experience required.

02

Intermediate builds

Design a robot's mechanics and electronics from a more open brief, with sensors and navigation.

03

Autonomous systems

Combine sensing, control, and (optionally) AI to build a robot that operates with less direct input.

04

Showcase & compete

Present the finished build, and where relevant, prepare it for a robotics competition.
